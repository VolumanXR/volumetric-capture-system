# Hardware and Capture System

## Overview
This section contains all the necessary designs, code, and documentation related to building the physical volumetric capture rig and controlling it through software.

### Contents:
- **CAD Designs**: 3D models of the camera rig and related hardware.
- **Firmware**: Low-level control software for the camera system.
- **Capture Software**: Software used to capture, synchronize, and manage volumetric data from the camera rig.

---

## Installation and Setup
Follow the instructions in the respective subfolders for setting up the camera rig and software.
